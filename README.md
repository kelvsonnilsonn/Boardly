# Boardly

## Requisitos Funcionais:

* O usuário deve poder criar uma anotação
* O usuário deve poder editar uma anotação
* O usuário deve poder excluir uma anotação
* O usuário deve poder modificar o status de uma anotação
* O usuário deve poder adicionar tags em suas anotações
* O usuário deve poder adicionar data de inicio e data de fim na anotação
* O usuário deve poder ver suas anotações

* O usuário deve poder criar dashboard
* O usuário deve poder excluir dashboard
* O usuário deve poder ver o seu dashboard
* O usuário pode ser proprietário/participante de vários projetos (dashboard)
* O usuário deve poder adicionar membros/parceiros ao seu dashboard
* O usuário deve poder remover membros/parceiros do seu dashboard
* O usuário deve poder atribuir uma anotação a um parceiro do seu dashboard
* O usuário deve poder adicionar uma anotação ao dashboard
* O usuário deve poder remover uma anotação do dashboard
* O usuário deve poder atribuir uma anotação a um parceiro do dashboard
* O usuário deve poder organizar as anotações no dashboard
* O usuário deve poder alterar o layout das anotações no dashboard
* O usuário deve poder visualizar o status das anotações no dashboard
* O usuário deve poder editar anotações dos parceiros do dashboard
* O usuário deve poder alterar o status de uma anotação de outro parceiro do dashboard
* O usuário deve poder mover as anotações dos parceiros do dashboard
* O usuário deve poder ver o dashboard que faz parte como parceiro ou é proprietário

## Requisitos Não-Funcionais:

* O sistema deve usar Vercel para hospedar
* O sistema deve usar Firebase para serviços de back e persistência
* O sistema deve registrar data e hora de criação de cada anotação
* O sistema deve garantir que só acesse o que é, de fato, participante ou proprietário usuário
* O sistema deve ser responsivo
* O sistema deve ser simples de ser entendido e aprendido
* O sistema deve garantir a persistência dos dados
